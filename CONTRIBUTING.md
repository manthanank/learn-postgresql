# Contributing to Learn PostgreSQL

Thank you for contributing to this enterprise PostgreSQL masterclass!

## How to Contribute
1. Fork the repository and create a feature branch (`git checkout -b feature/topic`).
2. Adhere strictly to the Beginner-to-Expert roadmap.
3. Ensure all Mermaid diagrams use quoted node labels for special characters.
4. Provide detailed line-by-line explanation tables for SQL scripts and DDL statements.
5. Run tests via `npm test` before submitting your pull request.
